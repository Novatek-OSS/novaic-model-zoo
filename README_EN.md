# Novatek Novaic Model Zoo

Novatek Novaic Model Zoo provides a comprehensive collection of deployment-ready AI models optimized for Novatek AI chip solutions. Generated by the Novatek Novaic Toolchain and integrated with the Novatek AI SDK, these models enable developers to efficiently build, evaluate, and deploy high-performance AI applications on supported edge computing platforms.

With a broad selection of pre-optimized models spanning image classification, object detection, semantic segmentation, and other AI applications, the Model Zoo significantly reduces development effort and deployment time. It serves as a complete starting point for accelerating AI innovation, helping developers rapidly transform concepts into production-ready edge AI solutions on Novatek hardware.

## Supported Chips
- HW CNN25 chips: NT9832x/NT9833x/NT9852x/NT98530/NT9856x
- HW CNN30 chips: NT98533/NT98538/NT98539A/NT98635/NT9869x

## Supported SDKs
- AI2 SDK: running on CNN25 chips
- AI3 SDK: running on CNN30 chips
